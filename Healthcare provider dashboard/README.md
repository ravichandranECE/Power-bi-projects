🏥 Healthcare Provider Performance Dashboard

A comprehensive data analytics project designed to track and analyze healthcare operational efficiency and financial performance. This dashboard provides stakeholders with real-time insights into patient volume, billing trends, and departmental resource allocation.

📊 Project Overview

This multi-page interactive dashboard (built with Power BI) visualizes key performance indicators (KPIs) for healthcare providers. It enables deep-dive analysis of patient stays, billing accuracy, and departmental revenue to improve decision-making and patient care outcomes.
